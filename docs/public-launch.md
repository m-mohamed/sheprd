# Public launch checklist

- [ ] `just check` passes.
- [ ] CLI help and JSON failure smoke pass.
- [ ] Plugin manifest contains only the readiness action.
- [ ] README, agent guide, and command reference agree.
- [ ] Ratatui cockpit points to the current Sol/Luna runbook.
- [ ] No retired peer-agent or legacy fleet references remain in active code,
      scripts, or plugin metadata.
- [ ] Dirty repository WIP is preserved and explicitly reported.
