# Sheprd Docs

Sheprd is a small Herdr companion. These docs are intentionally narrow: they
explain how to enter the right Herdr workspace, how agents should consume the
CLI, and which gates must pass before a release.

## Start Here

- [Product foundation](product-foundation.md): the public boundary and what
  Sheprd is allowed to own.
- [Herdr precedent](herdr-precedent.md): what Sheprd learns from Herdr without
  cloning Herdr.
