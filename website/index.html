Source-first install.

sheprd stays small while the public contract settles. Install Herdr separately, then install sheprd from source.

git clone https://github.com/m-mohamed/sheprd
cd sheprd
scripts/install-local.sh

Fast path.

Check the machine, list projects, connect. Use a sample recipe only when you want sheprd to shape a fresh workspace.

sheprd doctor
sheprd list
sheprd connect my-project
sheprd connect my-project --recipe agent-dev

Sesh for Herdr.

tmux made sessions powerful. Sesh made them fast to choose. Herdr brings runtime awareness to agents. sheprd brings the project picker layer.

tmux  : sesh
Herdr : sheprd

Agent-safe.

Agents can use JSON output and no-attach mode without accidentally nesting Herdr clients or guessing live runtime IDs.

sheprd doctor --json
sheprd list --json
sheprd connect my-project --no-attach
