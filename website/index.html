Sheprd

Keep project routing boring. Let Ratatui be the command center, Herdr be the runtime, and HQ own bounded Sol/Luna work.

Boundary

Sheprd discovers canonical Git projects, focuses Herdr workspaces, applies the explicit editor-first recipe, and checks readiness. Retired peer-agent and legacy fleet integrations are absent.

sheprd list --json
