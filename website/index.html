# contract

Opinionated where it matters.

Herdr owns the runtime. Sheprd owns the route from a clean Git project to one inspectable four-agent operating loop.

Visible

Exactly four named agents. No hidden subagents, mystery harness, or fifth worker.

Isolated

Pi stays in the clean base. Every worker receives its own branch and worktree.

Recoverable

Transactional launch, atomic receipts, clean-only rollback, typed-confirmation cleanup.

Git project → nonce-bound plan → isolated implementation → bounded code-run checks → two reviews → private receipt
# quick-start

Open, inspect, conduct.

$ herdr plugin action invoke m-mohamed.sheprd.doctor
$ herdr plugin action invoke m-mohamed.sheprd.open-flok
$ sheprd factory run my-app --task "bounded change" --plan-file plan.json --allow-path src --check "cargo test" --json
