# documentation

Sheprd docs.

Start with the boundary: Herdr is the runtime; Sheprd opens and safely retires one visible four-agent Flok.

InstallOpenConductFactoryCleanupTrustReference

Install

herdr plugin install m-mohamed/sheprd
herdr plugin action list --plugin m-mohamed.sheprd
herdr plugin action invoke m-mohamed.sheprd.doctor

The build step verifies the exact release archive's SHA-256 and GitHub provenance. If no verified prebuilt is available, it performs a locked source build.

Open a Flok

herdr plugin action invoke m-mohamed.sheprd.open-flok
# or choose a configured project
herdr plugin action invoke m-mohamed.sheprd.choose-flok
A new Flok requires a clean checkout. An existing Flok is focused and health-checked, never silently reshaped.

Conduct visibly

herdr agent list
herdr agent prompt <name> '<bounded task>'
herdr agent wait <name> --until idle --timeout 120000
herdr agent read <name> --source recent --lines 120 --format text

Pi conducts. Codex, Claude Code, and OpenCode work in isolated branches/worktrees. Repository checks—not agent prose—are the proof.

Run the code-owned factory

sheprd factory run my-app \
  --task "add retry metrics" \
  --plan-file plan.json \
  --allow-path src/metrics.rs \
  --check "cargo test metrics" \
  --json

Pi supplies the typed plan. Sheprd isolates the worker, enforces scope, runs checks and independent reviews, and writes the receipt. Acceptance requires passing checks and both approvals. Rejection preserves the worker checkout.

Preview, then confirm

herdr plugin action invoke m-mohamed.sheprd.cleanup-preview
herdr plugin action invoke m-mohamed.sheprd.cleanup-flok

The overlay requires the project name. Dirty or out-of-scope paths are preserved, branches are never deleted, and the state receipt is archived.

Know what runs

Herdr plugins execute as your user and are not sandboxed. Review herdr-plugin.toml, scripts/install-plugin.sh, and the runtime scripts before installation. Doctor cannot prove model credits or billing.
