Herdr project router

Sheprd docs.

Sheprd resolves canonical projects, focuses Herdr workspaces, applies small recipes, and reports readiness. Ratatui owns command-and-control; HQ owns Sol/Luna bounded execution.

Install

herdr plugin install m-mohamed/sheprd

Commands

factory --json
sheprd list --json
sheprd connect my-app --recipe agent-dev
sheprd doctor --json
sheprd show-config

Sol/Luna

Use the explicit HQ launcher from a Herdr-managed pane with a Tuxedo task ID, allow paths, checks, and a human acceptance gate.

~/workspace/hq/workflows/sol-luna-launch.sh \
  --project my-app --task-id my-app --task-number 1 \
  --task "bounded outcome" --allow-path src --check "cargo test"
